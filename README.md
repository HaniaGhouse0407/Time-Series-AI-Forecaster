## 🧠 Overview

Interactive forecasting dashboard supporting LSTM (PyTorch), Prophet, ARIMA, and ensemble methods. Upload your own CSV or choose from built-in datasets (stock, temperature, energy, sales). Reports MAE, RMSE, MAPE, and R².

---

## ✨ Features

- ✅ LSTM (PyTorch) with configurable hidden size, layers, dropout
- ✅ Prophet with trend, yearly/weekly/daily seasonality
- ✅ ARIMA with automatic order selection
- ✅ Ensemble: weighted average of LSTM + Prophet
- ✅ MAE, RMSE, MAPE, R² evaluation on held-out test set
- ✅ Forecast table with CSV download

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/HaniaGhouse0407/Time-Series-AI-Forecaster.git
cd Time-Series-AI-Forecaster

# 2. Install dependencies
pip install -r requirements.txt

# 3. Set environment variables (if needed)
cp .env.example .env
# Edit .env with your API keys

# 4. Run
streamlit run app.py
```
